# Eleken design system (observed)

## Feel
Warm cream canvas, generous whitespace, centered hero, typography-led. No hero photography. Soft white cards on `#F6F4F2`. Black CTAs. Quiet grey secondary text. Premium SaaS agency calm — not brutal, not dark.

## Tokens
- Background: `rgb(246, 244, 242)` / `#F6F4F2`
- Ink: `rgb(29, 30, 34)` / `#1D1E22`
- Body: `rgb(51, 51, 51)` / `#333333`
- Muted: `rgb(113, 113, 113)` / `#717171`
- Card: `#FFFFFF`
- Border: soft `rgba(0,0,0,0.06–0.08)`
- Radius: ~10–12px buttons/cards
- Display font: Regolapro (500), ~52px hero, tracking `-1.5px`
- Body font: Inter Variable, 15px / 25px

## Section patterns (home)
1. Sticky nav + black “Get started”
2. Centered text hero + dual CTAs + micro social proof
3. 8-up metric cards (stat + caption + faint logo)
4. Problem/pain 6-card board
5. Services blocks
6. Case result highlights
7. Process / how we work
8. Testimonial carousel / quotes
9. FAQ accordion
10. Footer with address columns
